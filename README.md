# CYBERFICTION

A futuristic, immersive web experience that blends cinematic storytelling, smooth scrolling, and striking 3D-inspired animation into a visually compelling digital journey.

## Overview

CYBERFICTION is a creative landing page concept designed to showcase a bold vision of the metaverse through elegant motion design, modern typography, and engaging storytelling. The project highlights the fusion of technology and imagination, delivering a polished and memorable user experience.

## Features

- Immersive full-screen layout
- Smooth scrolling and animated transitions
- Futuristic visual design and typography
- Responsive structure for modern screens
- Interactive experience built with HTML, CSS, and JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger
- Locomotive Scroll

## Project Structure

- `index.html` — Main structure of the website
- `style.css` — Styling, layout, and visual design
- `script.js` — Animation and scroll-based interactions

## How to Run

1. Clone or download this repository
2. Open the project folder
3. Launch `index.html` in your browser
   or use a live server extension for a smoother preview

## About the Project

This project reflects a professional approach to web design and animation, combining creativity with technical execution to create an immersive digital experience. It is a strong example of how modern web technologies can be used to build visually striking and engaging interfaces.
